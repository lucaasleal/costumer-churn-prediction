# costumer-churn-prediction
This repo contains a project of Introduction to Machine Learning course of UFPE.


## 1.Como rodar o pré-processamento

Instale as dependências:
``` bash
pip install -r requirements.txt
```
Rode para pré-processamento de dados:
``` bash
python3 ./Entrega_1/preprocessing.py
```

Rode para treinamento e avaliação:
``` bash
python3 ./Entrega_1/model.py
```

Rode para plotar os gráficos de desempenho:
``` bash
python3 ./Entrega_1/evaluation_utils.py
```

Rode para plotar gráficos de qualidade:
``` bash
python3 ./Entrega_1/analysing_quality.py
```

Rode para plotar os gráficos de correlação:
``` bash
python3 ./Entrega_1/analysing_correlation_bins.py
```

Os resultados podem ser observados na pasta a seguir:
``` bash
./Entrega_1/results/
```
